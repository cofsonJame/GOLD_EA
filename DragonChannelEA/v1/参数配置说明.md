# DragonChannel XAUUSD M5 EA 参数配置说明

本策略是专为 **黄金 (XAUUSD)** 在 **M5 (5分钟周期)** 图表上设计的趋势跟踪 EA，依赖 `DragonChannel.mq5` 指标计算的趋势通道与动态止损轨。

---

## 基础交易设置 (Trading)

| 参数名称 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| **Lots** | `double` | `0.10` | 每次开仓的固定交易手数。 |
| **MagicNumber** | `ulong` | `20260907` | EA 订单魔术码。用于区分账户中其他 EA 或手动开仓的订单。 |
| **DeviationPoints** | `int` | `50` | 允许的最大滑点（单位：点 / Points）。 |

---

## 指标设置 (Indicator)

| 参数名称 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| **DragonIndicatorName** | `string` | `"DragonChannel"` | 调用的自定义指标文件名称。请确保该 `.ex5` 或 `.mq5` 文件位于 `MQL5/Indicators/` 目录下。 |

---

## 策略控制设置 (Strategy)

| 参数名称 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| **OnlyTradeM5** | `bool` | `true` | **风控保护**：为 `true` 时，若图表不为 M5 周期，EA 将拒绝初始化并暂停交易。 |
| **CloseOnTrendEnd** | `bool` | `true` | 当趋势转为震荡/侧向（Sideway）时，是否立即平掉当前持仓。 |
| **ReverseOnNewTrend** | `bool` | `true` | 当出现反向趋势信号时（如持有多单出现空头信号），是否平掉反向仓位并直接反手开仓。 |
| **UseClosedBar** | `bool` | `true` | 为 `true` 时读取已收盘 K 线（Shift=1）的信号与止损位，**有效防止指标重绘导致的误信号**；为 `false` 则实时读取未收盘 K 线（Shift=0）。 |

---

## 止损与移动止损 (Stop Loss)

| 参数名称 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| **UpdateStopLoss** | `bool` | `true` | 是否启用动态追踪止损。开启后将根据 DragonChannel 的上下轨止损线实时更新持仓止损价。 |
| **MinStopDistance** | `double` | `0.0` | 额外设置的最小止损缓冲距离（以价格单位计，例如 `0.50` 代表黄金 $0.50 美元）。用于防止止损过于贴近市价被频繁扫损。 |

---

## 风险控制与过滤 (Filters / Risk Protection)

| 参数名称 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| **MaxSpreadPrice** | `double` | `0.0` | 最大允许点差（以价格为单位，如 `0.30` 表示黄金 $0.30 的点差）。`0.0` 表示不启用点差过滤。 |
| **MaxDailyLoss** | `double` | `0.0` | 账户每日允许的最大亏损金额（单位：账户币种）。当当日权益回撤达到该值时，停止当日的新开仓。`0.0` 表示不启用。 |
| **MaxConsecutiveLosses** | `int` | `0` | 允许的最大连续亏损笔数。当连亏达到设定次数后暂停新开仓。`0` 表示不启用。每日零点会自动重置连亏计数。 |
| **CloseBeforeTradingStop** | `bool` | `false` | 交易时段暂停前平仓（预留接口，供未来扩展交易时间过滤时使用）。 |

---

## 核心逻辑简述

1. **多头开仓 (BUY)**：当 `Line2 > 上轨止损线` 且 `Line1 > 下轨止损线` 时判定为多头趋势，开立买单，初始止损设为 `下轨止损线`。
2. **空头开仓 (SELL)**：当 `Line2 < 上轨止损线` 且 `Line1 < 下轨止损线` 时判定为空头趋势，开立卖单，初始止损设为 `上轨止损线`。
3. **追踪止损 (Trailing SL)**：随新 K 线生成，多单止损仅向上抬升，空单止损仅向下拉低，严禁扩大风险。
4. **趋势结束平仓**：当价格不满足多头亦不满足空头判定条件时，判定为震荡局势，EA 将平仓离场观望。
